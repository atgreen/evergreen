Five alternating TorCL/SBCL samples on CPU 0 used the native-transfer opt-in,
retired-instruction counts from perf, and a bounded portable child runner
(`ulimit -v 4194304` plus a 300-second timeout) because this sandbox has no
systemd user bus. The benchmark disables native transfer while loading each
source file, then enables it before validation, training, warmup, and timing.
Every TorCL sample passed its checksum gate, reached T2 for every listed hot
function before and after timing, and recorded zero timed deoptimizations.
