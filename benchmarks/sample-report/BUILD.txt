The report was regenerated after admitting recursive outer segments. Recursive
calls made while a segment is active use the bounded legacy/native bridge, so
there is no nested segment chain or frame-ownership bypass.

The report uses five alternating TorCL/SBCL samples on CPU 0, a bounded 4 GiB /
300-second child runner, --native-transfer, and process-wide retired instruction
counts. Every TorCL sample passed its checksum gate, reported T2 for every hot
function before and after timing, and recorded zero timed deoptimizations.

Fibonacci F(30), ten evaluations per workload:
  TorCL median 33 ms
  SBCL median 57 ms

Ironclad POWER-MOD, 100,000 modular exponentiations:
  TorCL median 529 ms
  SBCL median 10 ms

Caught conditions, 2,000 calls through HANDLER-CASE repeated 100 times:
  TorCL median 350 ms
  SBCL median 5 ms

Historical baseline is commit 2c84d2e1; the HTML and JSON retain all samples,
checksums, tier evidence, instruction counts, source hashes, and binary hashes.
These are local workstation measurements, not universal performance claims.
