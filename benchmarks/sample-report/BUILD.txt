The report was generated with five alternating TorCL/SBCL samples on CPU 0,
using a bounded 4 GiB / 300-second child runner. Every TorCL sample passed the
checksum gate and reported T2 for both timed functions before and after timing.
Retired instructions were collected process-wide with `perf stat` using the
`cpu_atom/instructions/` event; those counts include startup and compilation
and are supplemental to the in-Lisp throughput timer.

Fibonacci F(30), ten evaluations per workload:
  TorCL median 33 ms (samples 33, 34, 33, 32, 33)
  SBCL  median 56 ms (samples 57, 56, 56, 56, 57)
  TorCL median instructions 7,804,391
  SBCL  median instructions 7,882,683

Ironclad POWER-MOD, 100,000 modular exponentiations:
  TorCL median 527 ms (samples 527, 526, 534, 531, 523)
  SBCL  median  10 ms (samples  10,   9,  10,  10,  10)
  TorCL median instructions 7,807,043
  SBCL  median instructions 7,882,142

These are local workstation measurements, not universal performance claims.
The HTML and JSON retain the machine, runtime, source, runner, and binary
hashes. The report includes no native-transfer-specific workload yet; the
27-case GC-stress suite remains the correctness evidence for this milestone.
